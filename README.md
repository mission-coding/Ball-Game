# Ball Game 🎮

A 2D platform game built with Python and Pygame. Control a ball, navigate platforms, avoid spikes, and aim for a high score.

## ✨ Features

- Platform-based gameplay and jumping
- Obstacles and spike hazards
- Score tracking and saved high score
- Custom graphics and game assets
- Restart option after game over

## 🕹️ Controls

| Key | Action |
|---|---|
| Left Arrow | Move left |
| Right Arrow | Move right |
| Enter | Restart after game over |

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Run the game from its project directory:

   ```bash
   python ball.py
   ```

## 📁 Project Structure

- `ball.py` — Main game file
- `gallery/` — Game graphics and high-score data

Keep the asset folder alongside the Python file.
